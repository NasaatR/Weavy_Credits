# WEAVY CREDITS 1.8.0

[English](README.md)

Расширение Chrome для оценки расхода кредитов по сохранённым генерациям Weavy. На главном экране одна оценка расхода; исходные границы, подтверждённые списания и неизвестные стоимости сохранены в подробностях расчёта.

## Скачать и установить

[Готовый архив 1.8.0](https://github.com/NasaatR/Weavy_Credits/raw/refs/heads/main/downloads/WEAVY-CREDITS-1.8.0.zip). Требуется Chrome 116+. Node.js для установки не нужен. Это архив распакованного расширения, а не подписанный пакет Chrome Web Store.

1. Полностью распакуйте архив.
2. Откройте `chrome://extensions`, включите режим разработчика и нажмите «Загрузить распакованное расширение».
3. Выберите `WEAVY-CREDITS-1.8.0/extension/`.
4. Перезагрузите открытый проект `https://app.weavy.ai/` и откройте его сохранённую историю. Новая платная генерация не нужна.

Для обновления сохраните резервную копию в настройках, замените все файлы **прежней папки extension** и нажмите обновление установленного расширения. Сохраните прежнюю папку и установленное расширение: удаление расширения удаляет локальные данные. Затем перезагрузите вкладки Weavy.

## Быстро уточнить модель

В отчёте сразу под итогом видны модели без тарифа. Нажмите на поле модели, найдите подходящее название и выберите его: сохранение и пересчёт происходят сразу. Отдельной кнопки применения нет.

Выбор действует для эквивалентных названий во всех сохранённых файлах и для будущих генераций; область показана под полем. В «По запускам» доступно исключение для одной генерации, которое имеет приоритет над общим выбором. «Определять автоматически» убирает уточнение.

Например, `Seedream V5.0 Edit` автоматически соответствует `Seedream V5 Edit`. Другая минорная версия или конфликт исторических сведений требуют явного выбора. Похожие варианты идут первыми; свободно введённый текст сам не сохраняется.

## Скопировать диагностику

Откройте «Данные → Копировать диагностику», затем вставьте её в сообщение — **Ctrl+V**. Копируется тот же очищенный JSON, что скачивается кнопкой рядом. Статус подтверждает успешную запись в буфер. Если браузер её заблокировал, откроется выделенный текст: нажмите **Ctrl+C**, повторите копирование или скачайте JSON.

## Что улучшено в 1.8.0

- Any LLM: 360 текстовых моделей, включая Claude Opus 5, и модели, обнаруженные в ваших данных Weavy. Есть фильтр текстовых моделей и поиск по идентификатору провайдера. Модель без тарифа явно отмечается; справочник не обещает её наличие или определённую цену в Weavy. Ручные соответствия сохраняются.
- Распознаются выбранная LLM в типизированных параметрах и переданные счётчики токенов. Тариф за токены требует реальных счётчиков; отсутствующие цены не заменяются нулём или стоимостью другой модели. Текущие ценовые ориентиры не применяются к старым генерациям автоматически.
- Плавающая панель сохраняет элементы при обновлении. Перетаскивание использует захват указателя и кадры анимации; положение записывается после отпускания. Фоновые обновления откладываются на время движения, текущий файл не сбрасывается при обычном обновлении.
- В меню одновременно до 80 вариантов, поиск охватывает весь список. Признаки сходства кэшируются. Диагностика включает до 4 000 текущих цен и разные структуры нод.
- Установочный ZIP содержит только необходимые файлы, контрольные суммы и инструкции. Уже зафиксированный архив версии нельзя незаметно заменить другими байтами.

## Проверка архива и Defender

Статическая проверка `node scripts/audit-runtime.mjs` контролирует локальные ресурсы, CSP, разрешения и признаки динамического выполнения кода. Это не вердикт антивируса.

Windows-проверка в [GitHub Actions](https://github.com/NasaatR/Weavy_Credits/actions) обновляет базы Microsoft Defender, сканирует готовый ZIP и распакованные файлы, выводит SHA-256, версии движка/баз и результаты. Ошибка или недоступность сканера не считаются успешной проверкой. Смотрите фактический результат запуска для нужной версии.

Вердикт относится к проверенным байтам и указанным версиям баз. Ошибочное срабатывание можно передать на пересмотр [Microsoft Security Intelligence](https://www.microsoft.com/en-us/wdsi/filesubmission); окончательное решение принимает Microsoft. Расширение не изменяет настройки защиты Windows.

## Точность и данные

Полнота истории за всё время не подтверждена: недоступные результаты и отсутствующие суммы списаний нельзя восстановить из пустых данных. При неизвестных параметрах исходный диапазон сохраняется в аудите; на основном экране показывается его середина как приблизительная оценка. Без тарифа стоимость остаётся неизвестной. Текущие настройки ноды не подставляются вместо исторических. Каталог не доказывает фактический расход аккаунта. [Источники и границы тарифного расчёта](docs/PRICING-RESEARCH.md).

Разрешения: `sidePanel` для отчёта, `storage` для локальных данных, `app.weavy.ai` для наблюдения истории и `www.cbr.ru` для необязательного обновления курса. Сервер и аналитика отсутствуют. Полная резервная копия и сырые экспорты могут содержать данные проектов; проверяйте их перед передачей. Аудит расчёта заменяет идентификаторы и исключает промпты, медиа и названия проектов.

Проверены **252 тест расширения и 10 исходных тестовых файлов** на синтетических данных. Отрисовка в Chrome и реальные списания авторизованного Weavy в этой среде не проверены. [Подробности проверки](docs/TESTING.md).

## Разработка

Для разработки: Node.js 24+, npm, Python 3.9+: `npm ci`, `npm run build`, `npm test`, `npm run test:reference`. Готовые сборки включены в репозиторий.

`npm run preview` — интерфейс с искусственной историей по адресу `http://localhost:18765`; параметры `?width=320`, `?font=22`, `?theme=light`. Предпросмотр подменяет Chrome API и не подключается к аккаунту Weavy. `npm run package` собирает готовый архив (только для упаковки требуется Python 3).

Для ошибок: [Issues](https://github.com/NasaatR/Weavy_Credits/issues), версия расширения/Chrome, воспроизведение и предварительно проверенный аудит расчёта. Не публикуйте токены, личные проекты и сырые платёжные выгрузки.
