# Проверка 1.8.0 — 27.10.2026

`npm test`: **252 / 252**. `npm run test:reference`: **10 / 10** исходных тестовых файлов. Локальный полный вывод: [test-output.txt](test-output.txt), [reference-test-output.txt](reference-test-output.txt).

Новые проверки охватывают каталог LLM, выбор модели Any LLM в типизированных параметрах, приоритет исторической модели, явные счётчики токенов и ручной тариф за входные/выходные токены. Отсутствующие счётчики и неподтверждённая цена остаются неизвестными. Проверены модели из наблюдаемых данных, отсутствие изменения ручных исправлений и отсутствие подстановки текущего ценового ориентира в исторический расчёт.

Для перетаскивания проверены 100 событий указателя за один визуальный кадр, отсутствие повторных измерений размеров, сохранение только при отпускании, захват указателя, отмена/границы, работа кнопок и игнорирование чужого указателя. Интеграционный сценарий собранной панели подтверждает сохранение тех же элементов, отложенный фоновый пересчёт и отсутствие сброса суммы при движении.

Меню ограничено 80 отображаемыми вариантами; точная модель за пределами первого окна находится поиском и выбирается клавиатурой. Проверены LLM-фильтр, видимость Claude Opus 5 и пустая цена/единица «запуск» в форме нового тарифа.

Проверки упаковки подтверждают полный граф зависимостей, отсутствие посторонних файлов, запрет ссылок за пределы extension и неизменность архива уже зафиксированной версии. ZIP содержит контрольные суммы файлов; внешняя SHA256SUMS идентифицирует байты архива. Контрольная сумма не является подписью или гарантией отсутствия угроз.

Статический аудит проверяет разрешения, CSP, локальность ресурсов и отсутствие динамического выполнения/нативных команд в runtime. Это отдельная проверка, не замена Microsoft Defender. Windows-job в GitHub Actions обновляет базы Defender, сканирует архив и распакованные файлы без изменения глобальных исключений/настроек защиты и записывает движок, базы, SHA-256 и результаты. Недоступность движка, ошибка сканирования, обнаружение или изменение файлов не считаются чистым результатом. Фактический результат проверяется после публикации.

Каталог включает 188 прежних моделей/вариантов цен и 360 текстовых идентификаторов из публичного API OpenRouter, проверенных 27.10.2026. Из справочника не импортируются цены API, промпты, описания или ключи. Это не доказательство наличия всех моделей в Weavy; наблюдаемые модели добавляются в список отдельно. Тарифы Weavy не выдумываются.

Тестовые данные синтетические. Личные экспорты и скриншоты не входят в репозиторий или архив. Реальный финансовый журнал, платные генерации и авторизованный аккаунт Weavy не использовались для проверки. Полный визуальный прогон Chrome в этой среде недоступен; DOM-тесты не заменяют измерение реальной частоты кадров.
