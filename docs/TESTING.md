# Проверка 1.7.0 — 27.10.2026

`npm test`: **237 / 237** проверок расширения, без пропусков и отмен. `npm run test:reference`: **10 / 10** исходных тестовых файлов. Полный вывод: [test-output.txt](test-output.txt), [reference-test-output.txt](reference-test-output.txt). Эти тесты не подтверждают актуальность всех тарифов аккаунта или исторические списания.

Десять новых регрессий к версии 1.6.1 проверяют:

- Среднюю оценку, неизменность подтверждённых сумм, отсутствие придуманного нуля для неизвестного расхода и численную устойчивость середины больших границ.
- Один итог при сочетании факта, оценки и неизвестного расхода; сохранение обеих границ и метода оценки в аудите.
- Сортировку по контексту сервиса при общем историческом названии без автоматической подстановки другой версии.
- Проверенный endpoint Flux Max Edit и запрет наследования его цены другим режимом/версией.
- Предупреждение при отсутствии модели в каталоге и отсутствие выбора первой строки по Enter без подтверждения.
- Отсутствие ложной близости разных семейств из-за общего префикса провайдера.
- Приоритет нового поискового запроса над контекстом ноды и отсутствие автосохранения подсказки.
- Один итог в собранной панели, совпадающий с расчётом отчёта; видимый признак неучтённых записей.
- Попадание нужного тарифа из конца длинного списка в диагностику и точное число пропущенных примеров.
- Выбор проблемных семейств в примерах сохранённых результатов и сохранение обезличивания.

Существующие DOM-проверки обновлены под один основной итог, соответствующий пересчёт валют, закрытые по умолчанию подробности и полный список вариантов. Сохраняются проверки параметров каждого результата, исторических моделей, возвратов, дедупликации, уточнений, резервных копий и изоляции сообщений страницы.

`npm run build` использует закреплённый esbuild 0.28.2, собирает локальные IIFE для Chrome 116+ и синхронизирует версию из package.json. `node scripts/build-catalog.mjs` воспроизводит каталог из сохранённых исходников. Новые разрешения и runtime-зависимости не добавлены. Числовые тарифы не заменены ценами стороннего провайдера; добавлено проверенное соответствие edit endpoint и сохранены даты исходных цен.

Все опубликованные fixtures — искусственные. Личные диагностические экспорты и отчёты не включаются в репозиторий или установочный ZIP. Авторизованный Weavy, платные генерации и финансовый журнал аккаунта не использовались. Старая диагностика без HTTP-статусов не позволяет установить, какие ответы сети не загрузились, и не содержит отсутствовавших сумм списания.

`npm run preview` использует реальные компоненты UI, искусственную историю и mock Chrome API. Визуальная отрисовка в Chrome и реальные списания не проверены: облачный браузер не имеет доступа к локальному серверу этой среды. DOM-проверки не заменяют браузерный прогон.

ZIP проверяется на целостность, согласованность версии, наличие всех модулей и побайтовое совпадение extension с проверенными исходниками. SHA-256 находится рядом с архивами. GitHub Actions повторяет сборку, проверку её воспроизводимости и оба набора тестов на Node 24; фактический результат проверяется после публикации.
