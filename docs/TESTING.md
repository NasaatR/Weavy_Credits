Размер content.js + observer.js: **337 402 байта** против **649 810** в 1.5.0, уменьшение **48,08%**. Это размер файлов, не измерение скорости Chrome или точности списаний. Runtime-зависимости и разрешения не расширены. Готовый ZIP проверен на целостность, версию manifest, отсутствие зависимостей npm и побайтовое совпадение файлов extension с исходниками; SHA-256 опубликован рядом с архивом.

HTTP-предпросмотр проверен на перенаправление к панели, доступность CSS/модулей и ограничение маршрутов. `npm run preview` открывает настоящие компоненты UI с подменённым Chrome API и синтетической историей. В облачном браузере `localhost` недоступен (`ERR_CONNECTION_REFUSED`), поэтому визуальная проверка отрисовки, фокуса и прокрутки в Chrome не выполнена. Геометрия меню и взаимодействия проверены DOM-тестами; это не заменяет браузерную отрисовку.

Авторизованный Weavy, реальная история списаний и платные генерации не использовались. Отсутствующие исторические параметры не восстановлены искусственно, финансовая полнота не заявляется.
