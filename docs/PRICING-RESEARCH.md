Повторно прочитаны официальные таблицы Image, Edit Image и Video, статья о системе кредитов и инструкция Credit Usage Log. Таблицы предупреждают, что могут отставать от интерфейса Weave. Дата проверки остальных семи таблиц и исходных 147 строк остаётся 22.09.2026.

Из уже сохранённых числовых правил выделены 40 именованных вариантов. Это раздельные версии и режимы, а не 40 новых неподтверждённых моделей или новые цены. Пять вариантов Kling взяты из общей колонки Kling Video; 35 вариантов с явным Fast/Standard/Pro/Lite и другими режимами сохраняют условия своих исходных строк. Каталог содержит 148 исходных позиций и 40 производных вариантов.

Найдены два существенных расхождения. Для Gemini 3 Pro таблица публикует 15–30, тогда как прежний анализатор содержит 11/23. Поскольку часть этого набора выходит за официальный диапазон, весь набор подробных правил не выбирает одну цену: остаётся официальный диапазон и пояснение. Для Kling 2.6 Pro таблица дважды указывает 5 секунд с разными ценами, 120 и 180. Прежнее правило 180 за 10 секунд не подтверждено строкой; 1.5.0 его не использует.

На [Nano Banana 2.1](https://help.weavy.ai/en/articles/17336697-nano-banana-2-1-launch-promotion) и [Seedance 2.5 для годового Max](https://help.weavy.ai/en/articles/17636512-seedance-2-5-max-plan-launch-promotion) опубликованы отдельные акции с условиями по датам и праву участия. Их нельзя применить ко всей прошлой истории по текущему названию подписки. В этой версии не добавлены выдуманные базовые цены и ретроспективные скидки без доказательств участия и условий конкретного запуска.

Официальный [Credit Usage Log](https://help.weavy.ai/en/articles/13751776-credit-usage-log) скачивается через Settings → Workspace Settings → Credits → Download Credits Usage History. Это подходящий источник для сверки фактического расхода; реальный файл с его колонками и стабильными связями с запусками не предоставлен, поэтому универсальный импорт CSV не объявляется работающим.

Ни одна публичная таблица и ни один локальный тест не подтверждают точность итога конкретного аккаунта. Ниже сохранён исходный датированный обзор. Старые подробные правила применяются с ограничениями 1.5.0, описанными выше.

## Стоимость кредита

[Официальная система кредитов Weavy](https://help.weavy.ai/en/articles/12267166-figma-weave-s-credit-system), опубликовано 02.06.2026:

| Пополнение | USD за кредит | USD за 10 000 кредитов |
|---|---:|---:|
| Starter: $10 / 1 000 | 0,01 | 100 |
| Pro / Team: $10 / 1 200 | 1 / 120 | 83,333333… |

Это цены пополнения. Цена включённых в подписку кредитов зависит от оплаченного плана и периода; она не смешивается с top-up автоматически. Для неё есть ручной ввод цены. [Тарифы подписки](https://weave.figma.com/pricing), [справка о планах](https://help.weavy.ai/en/articles/12267070-figma-weave-s-subscription-plans).

Автоматический режим берёт `creditsPerDollar` из уже наблюдаемого ответа Weavy для выбранного рабочего пространства. Никакие новые запросы к неизвестным API не добавлены. При отсутствии данных используется явно подписанное допущение Pro/Team; это не определение плана пользователя. При неоднородных ценах нескольких рабочих пространств деньги остаются неизвестными, пока не выбран один workspace или ручная общая цена.

## Курс доллара

[ЦБ РФ: курс на 22.09.2026](https://www.cbr.ru/currency_base/daily/?UniDbQuery.Posted=True&UniDbQuery.To=22.09.2026): USD 84,0954 RUB за одну единицу.

[XML ЦБ на ту же дату](https://www.cbr.ru/scripts/XML_daily.asp?date_req=22/09/2026) проверен отдельно. Датированный запрос нужен, чтобы не принять уже опубликованный курс следующего дня. Расширение запрашивает текущую московскую дату, проверяет USD, номинал и дату, отклоняет будущий курс и ответ старше десяти дней. Обработка не требует cookies или авторизации. Ошибка сети не обнуляет сохранённый курс. Курс ЦБ является расчётным ориентиром; курс покупки и комиссию можно учесть вручную.

## Расхождения и принятые правила

- GPT Images 2 / Edit: в официальной таблице 1–37, в предоставленном каталоге были правила 9 за medium и 37 за high. В 1.0.4 подробное правило применяется при известном Quality; источник «Предоставленный анализатор 0.20.0 · 2026-07-28» указывается в записи. При отсутствующем/неподдержанном Quality остаётся диапазон 1–37.
- Nano Banana 2: опубликовано 4–18; правила 6/9/13,5 из предоставленного анализатора применяются при известном разрешении и отдельно обозначены как тарифная оценка по этому источнику, не подтверждённая текущим списанием.
- Gemini 3 Pro: опубликовано 15–30; правила 11/23 из предоставленного анализатора применяются только при известном разрешении, с отдельным указанием источника. Они не объявляются актуальным официальным тарифом.
- Seedream V5 Edit: опубликовано 4. Псевдоним Seedream V5.0 Edit поддержан. Неполное «V5.0 Pro» не является подтверждённым названием той же модели.
- Динамические варианты скопированы из предоставленного каталога только для строк, где все числовые цены найдены в официальной строке; их параметры и исходная строка сохранены для проверки. Линейная интерполяция промежуточных длительностей не добавлялась.
- Seedance 2.0: источник отдельно сообщает, что 1080p имеет другие цены. Сохранённое разрешение 1080p не оценивается по базовым вариантам.
- Beeble SwitchX: формула прежнего каталога сохранена с отдельной отметкой, без заявления о текущей официальной проверке.
- Ручные тарифы с явно заданными датами/условиями имеют приоритет. Несколько совпадающих ручных тарифов дают неизвестную сумму, а не автоматическую подмену каталогом.

Встроенные цены применяются только к оценкам. Для подтверждённых прошлых списаний нужны сами операции; новый прайс не реконструирует их.

Новые варианты GPT Image 2.5 и Nano Banana 2 Lite исключены из приблизительного сопоставления со старыми моделями. Публичный каталог не дополнен выдуманными для них параметрическими правилами. Текущая цена меню без условий не используется как цена всех прошлых вариантов.
